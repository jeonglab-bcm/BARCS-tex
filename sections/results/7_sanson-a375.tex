\subsection{Endpoint benchmark and copy-number audit}
\label{sec:sanson}

We used the Brunello A375 negative-selection screen of
\citet{sanson2018optimized}, bundled with CB\textsuperscript{2}, as a
descriptive endpoint benchmark.  Reference essential genes are positives and
reference nonessential genes are negatives \citep{hart2017evaluation}.  The
common copy-number-complete set contains 1,506 essential and 869 nonessential
genes, so its positive prevalence is 63.4\%.  F1 and recall in this enriched
set need to be read alongside the realized false-discovery proportion.

Copy number is a gene-level property of A375 and is constant across the
plasmid and terminal libraries, so it cannot be identified as a sample-level
coefficient.  We instead applied MAGeCK 0.5.9.5's official post-fit piecewise
correction to both methods' gene effects using the A375 profile from DepMap
Public 19Q3 \citep{depmap19q3,meyers2017cnv}.  This changes effect rankings
but does not refit either count likelihood.

BARCS ranked the reference genes slightly better than MAGeCK-MLE before copy-number
correction (AUROC 0.963 versus 0.960; average precision 0.981 versus 0.980)
and, at a nominal FDR of 0.05, recovered 17.1 percentage points more of the
essential genes (paired bootstrap 95\% CI 15.2 to 19.1), at the cost of a
larger realized FDP within the gold-standard set (0.023 versus 0.007).
CNV correction removed most of the nuisance association with copy number
(Table~\ref{tab:sanson}), from $-0.185$ to $0.003$ for BARCS and from $-0.207$
to $-0.006$ for MAGeCK-MLE, but lowered AUROC for both methods.  After
correction, the BARCS--MAGeCK AUROC difference was 0.0017 (95\% CI $-0.0039$
to $0.0073$) and the average-precision difference was 0.0008 (95\% CI
$-0.0017$ to $0.0031$), so the two methods ranked genes equally well; the
main difference between them is that BARCS calls more essential genes at the
same nominal threshold.
